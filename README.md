# Kalkulator Sederhana

Aplikasi kalkulator berbasis web yang dibuat menggunakan **HTML, CSS, dan JavaScript**. Project ini dapat dijalankan langsung melalui browser dan dapat dipublikasikan menggunakan GitHub Pages.

## Fitur
- Penjumlahan (+)
- Pengurangan (-)
- Perkalian (×)
- Pembagian (÷)
- Persentase (%)
- Bilangan desimal
- Tombol hapus satu karakter (DEL)
- Tombol reset (AC)
- Dukungan keyboard: angka, operator, Enter, Backspace, dan Escape
- Tampilan responsif untuk layar komputer maupun ponsel

## Teknologi
- HTML5
- CSS3
- JavaScript

## Cara Menjalankan
1. Unduh atau clone repository ini.
2. Buka folder project.
3. Klik dua kali file `index.html`, atau buka file tersebut menggunakan browser.
4. Kalkulator siap digunakan.

## Cara Menjalankan dengan GitHub Pages
1. Buat repository baru bernama `kalkulator`.
2. Upload file `index.html`, `style.css`, `script.js`, dan `README.md` ke repository.
3. Buka **Settings** → **Pages**.
4. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
6. Tunggu proses publikasi selesai. Alamat website akan ditampilkan pada halaman GitHub Pages.

## Struktur Folder
```text
kalkulator/
├── index.html
├── style.css
├── script.js
└── README.md
```
